# FMCW 生命体征雷达仿真代码（60 GHz 呼吸/心跳检测）

一套纯仿真的毫米波 FMCW dechirp 雷达链路，用于验证从含杂波、相噪、体动的回波中提取胸腔微动（呼吸 / 心跳）的完整信号处理链。核心链路不依赖任何 MATLAB 工具箱，附 Python 同源数值验证脚本。

## 3. 物理模型

### 3.1 系统拓扑
单发单收（1T1R）、60 GHz、Up-chirp 的 FMCW dechirp 雷达。真实硬件里 dechirp 由模拟混频器完成，ADC 只需采差频（拍频）带宽——仿真用解析等效（`exp(j·2πf·t)` 复指数）复现这一点，因此快时间按拍频 `fb_max` 采样而非按 chirp 带宽采样。

### 3.2 相位—位移关系（检测的物理基础）
胸腔微动 `ΔR(t)` 引起回波相位变化：

```
φ(t) = 4π·ΔR(t) / λ
```

60 GHz 下 `λ = 5 mm`，故 1 mm 位移 ≈ 1.4 rad 相位摆动；呼吸 1 mm、心跳 0.25 mm 的位移对应可测的相位调制。目标：从慢时间相位序列里分离出 0.25 Hz（呼吸）与 1.10 Hz（心跳）两个频率峰。

### 3.3 回波构成（离散散射点模型）
不用统计杂波场（`constantGammaClutter` 那类公里级地杂波模型对室内近距不适用），而是几个确定性散射点，各自带距离与相对幅度：

| 散射点 | 距离 | 相对幅度 | 是否随身动 | 角色 |
|---|---|---|---|---|
| 墙 | 0.80 m | 0.60 | 否（静止） | **相噪参考 bin** |
| 胸腔 | 1.50 m | `S.targetAmp`（0.05/0.5） | 是 | **目标**，微动主导其 bin |
| 躯干 | 1.80 m | 1.00 | 是 | 强静态反射，已移开避免同 bin 抵消 |
| 家具 | 2.30 m | 0.35 | 否（静止） | 远距静态杂波 |

**体动**同时带动胸腔与躯干（0.05/0.11 Hz 主次晃动 + 随机游走，峰峰约几 mm），是低频共模相位漂移。**相噪**用分段幂律 PSD（1/f² 近载波 + 白噪声底）频域整形生成，作为 common-mode 相位因子乘到所有 chirp 上。**接收噪声**为逐采样点的复高斯白噪声。

## 5. 处理链

```
回波 X(Nchirp × Nfast)
  → 距离窗(Hann) + 距离 FFT            → Xrng(Nchirp × Nfft_r)
  → 目标 bin / 墙 bin 求和              → z_t, z_wall
  → 相噪对消: z_t·exp(−j·pn_est)        → z_t_pc      (pn_est = 墙 bin 相位去均值)
  → 解缠相位 → 位移: φ·λ/(4π)           → ph
  → 滑动中值去趋势(去体动) + 线性兜底    → dR_proc
  → 频谱(Hann + zero-padding 2^16)      → 呼吸/心跳峰 + 显著性报告
```

**显著性判据**：`峰高 − 局部基底(dB)`，基底取 0.05–2.5 Hz 内远离目标频率 ±0.2 Hz 的中值，>5 dB 判为显著。这一步很关键——早先用"窗口内取最大值"判据骗过自己（只要窗里有噪声就会报峰），已废弃。

脚本同时输出**未做相噪对消的对照**，用于观察共模相噪的影响。

## 6. 验证结果（Python 同源，2026-11-17）

| 场景 | 呼吸 | 心跳 | 稳健性 |
|---|---|---|---|
| 演示幅度 0.5 + 完整链路 | 0.251 Hz (+40 dB) | 1.099 Hz (+26 dB) | 10/10 realization 双峰显著 |
| 真实比例 0.05 + 完整链路 | 0.251 Hz (+40 dB) | 1.099 Hz (+26 dB) | 与 0.5 几乎一致 |

真值为 0.250 / 1.100 Hz，检出精确。**胸腔幅度 0.05 与 0.5 结果一致**——躯干移开后目标 bin 由胸腔主导，相位只取决于位移、与回波幅度无关（见 §7 根因 3）。

> 说明：`peak_sig` 是相对基底的判据。在本仿真（相噪为合成、无硬件非理想）里，相噪对消对该判据的提升有限；它的真实价值在硬件共模相噪抑制。`fmcw_vitals_realworld_compare.png` 里蓝线（完整链路）与红虚线真值高度贴合，频谱双峰清晰。

## 7. 关键工程要点与踩坑记录

这部分是本代码最有价值的内容，都是实测踩出来的，改动前务必先看。

### 根因 1｜躯干与胸腔同 bin 导致微动矢量抵消（已修正）
初版把躯干放在 1.512 m、胸腔 1.50 m，仅差 12 mm。距离分辨率 5 cm（bin 宽 2.8 cm）下两者落在同一 bin，微动矢量在 bin 内相互抵消——目标 bin 实测相位 std 只有理论的 1/5.7（呼吸卡 17 dB / 心跳 3 dB）。**修正：躯干移到 1.80 m**。真实雷达里胸壁反射点自身在动、是其 bin 的主导散射点，身体其它部位分布在不同 bin——这才是正确建模。

### 根因 2｜back 参考的复数域体动对消反而破坏信号（已移除）
原处理链用 `ratio = z_t·conj(z_back)` 做体动对消，在 7 mm 体动（相位摆动 ~17 rad）下 unwrap 出错、残留巨大，反把心跳压到 5 dB。**修正：移除该步**。体动是 0.05/0.11 Hz 低频，与呼吸 0.25 / 心跳 1.1 Hz 频率完全可分，靠"相噪对消 + 滑动中值去趋势"就能干净分离。

### 根因 3｜20:1 "幅度压缩"是假象（叙事已废弃）
曾认为胸腔幅度 0.05（相对躯干 20:1）会把微动相位压缩 20 倍，并试过 arcsin 解压缩——那是错的：相位有直流偏置，除 k 后被 clip 成方波产生假峰。躯干移开后证明：相位 = `4πΔR/λ` 与幅度无关，0.05 和 0.5 一样强。压缩叙事及 arcsin 代码已全部删除。

### 采样率｜复信号 1.2× 而非 2× 的拍频采样
dechirp 输出是 I/Q 正交解调的复信号，单边谱只占 `0~fb_max`，带宽即 `fb_max`，复采样 `Fs ≥ fb_max` 即可，1.2× 是抗混叠余量。`2×fb_max` 只对实信号成立。真实硬件若有 I/Q 不平衡导致镜频泄漏，该修模拟前端，不是把 Fs 翻倍。

### 墙参考 bin 必须静止
墙是相噪参考（相位只含相噪），一旦让它随身动，相噪估计就会把体动误当成相噪，破坏对消。曾出现过注释写"墙静止"但代码给墙加了 body 的自相矛盾 bug，已修。

### 验证方法论
- **严格判据**：必须用"峰高−局部基底(dB)" + 多 realization 扫描，不能用"窗口内取最大值"。
- **跨语言差异**：numpy 广播与 MATLAB `repmat`/转置维度规则不同，MATLAB 脚本曾因 `repmat` 方向写反报"数组维度不一致"。散射点矩阵布局统一为 `nScat × Nchirp`（每行一个散射点、每列一个 chirp）。
- **实跑为准**：这台环境没有 MATLAB，主脚本通过静态检查（字段/函数/维度/参数对齐）+ Python 同源数值验证，但**未在 MATLAB 里实跑过**。以用户 MATLAB 实跑结果为准。

## 8. 局限与后续方向

- **无硬件实测**：全部为合成回波。相噪是 PSD 模型、无 1/f³ 闪烁段与真实振荡器数据；无天线方向图、无多径、无 ADC 量化（接口预留但默认关闭）。
- **体动为模型化**：主次晃动 + 随机游走是参数化的，未接真实人体微动数据。
- **相对幅度模型**：默认 `normalized`（直观）；`radareq` 模式按雷达方程算幅度，但未含相位噪声对 SNR 的完整链路预算。
- **单目标**：只有一个胸腔微动点，未处理多人、体动剧烈（>10 mm）等更难题况。
- 后续可推进：接真实 6843 采集的 IF 数据；相噪参考的工程实现（干净静止角反射器）；把 sliding median 换成更严谨的自适应体动对消。
